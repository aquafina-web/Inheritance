#Inheritance

Inheritance is when a class can use the properties and methods of another class. For example, a child class can get the features of a parent class.
This project was made to demonstrate inheritance in real life, like: grandparent -> parent -> child.

Step-by-step instructions on how to get it working: 
1. Click on run.
2. Enter the amount of land your grandfather has.
3. Enter the type of house your parents have.
4. Enter what car you have.
5. Done! (All the information will display in the output)

I learned about different types of inheritance, like, single inheritance, multilevel inheritance, etc. I also learned how inheritance works.

Tools used: 
Python (.py)
